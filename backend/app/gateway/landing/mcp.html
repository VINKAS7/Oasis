Oasis isn't in the ChatGPT or Claude app directories yet, so you add it as a custom connector. It takes about a minute, and the steps are below.

How to connect

ChatGPT
  1. Open ChatGPT settings and go to Apps & Connectors.
  2. Under Advanced settings, turn on Developer mode.
  3. Click Create, name it Oasis, paste the server address, choose No authentication and save.
  4. In a chat, pick Oasis under + → Developer mode, then ask away.
Claude
  1. Open Claude settings → Connectors.
  2. Click Add custom connector, name it Oasis and paste the server address.
  3. Click Add. It works in Claude on the web, desktop and mobile.
  4. In a chat, check that Oasis is on in the Search and tools menu.
Claude Code and other MCP clients

Claude Code:

claude mcp add --transport http oasis {{MCP_URL}}

Clients configured with JSON:

{
  "mcpServers": {
    "oasis": { "type": "http", "url": "{{MCP_URL}}" }
  }
}
